They guided the bar layout (brand + app name + menus left, status + clock
right), the floating dock (rounded translucent panel, app tiles, separator,
running dots), and the launcher (centered search field, result list, preview).

The shipped shell uses our own drawn mark, Tokyo Night tokens, Inter, and
Lucide/Adwaita symbolic icons; no Apple artwork is included.
